Private Android APK & AAB builder
Build your Android project through GitHub Actions. Your APK/AAB is produced by your own GitHub repository.

1. GitHub connection

Use a token with access only to this repository. The page does not save the token.

2. Android project

The ZIP must contain an Android Gradle project with gradlew, Gradle settings, and an app module.

How it works

The builder uploads your project to this repository as build-input.zip, starts the Build Android APK and AAB GitHub Action, and GitHub Actions creates the release APK/AAB.
